# 📇 Contact Manager Application

A full-stack Spring Boot application for managing personal contacts with secure authentication, CRUD operations, and image upload functionality. It uses Spring Security for user authentication, Hibernate for ORM, and Thymeleaf for dynamic frontend rendering.

---

## 🚀 Features

- 🔐 **User Registration**  
  New users can register and create an account.

- 🔑 **User Authentication & Login**  
  Secure login using Spring Security and OAuth2 (Google, GitHub).

- 📇 **Contact Management**  
  Logged-in users can:
  - Add new contacts  
  - Update existing contacts  
  - Delete contacts  
  - Upload images for each contact

- 📄 **Pagination**  
  Efficiently display and manage large numbers of contacts with pagination.

- 💻 **Responsive Design**  
  Built using Thymeleaf and responsive HTML/CSS for cross-device compatibility.
